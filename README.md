# FORME

FORME is a boutique e-commerce storefront concept focused on everyday objects that feel intentional, useful, and beautifully simple. The site showcases a curated collection of home and desk essentials such as lamps, organizers, storage pieces, bags, and decorative objects designed to make daily routines feel calmer and more considered.

This project is a front-end storefront demo with a polished shopping experience inspired by premium lifestyle brands. It includes product browsing, collection pages, search, cart functionality, store locations, customer support prompts, and a lightweight authentication flow for sign in and sign up.

## What the website is about

FORME is built around the idea that well-made objects can improve the way people live. Instead of clutter or disposable products, the brand emphasizes:

- Thoughtful, minimal design
- Natural materials and tactile finishes
- Useful everyday essentials for home and work
- A slower, more intentional lifestyle

The site presents a modern lifestyle brand experience for customers who care about design, functionality, and atmosphere.

## Features

- Responsive storefront landing page
- Product catalog with categories and collections
- Search and filtering for browsing products
- Shopping cart and checkout-style flow
- Store locator with Taiwan locations
- FAQ and customer support assistant
- Sign up / sign in demo authentication
- Server-side API routes for auth and health checks

## Tech stack

- HTML, CSS, and JavaScript for the storefront UI
- Node.js server for local development and static routing
- JSON-based local user storage for the demo auth flow
- Vercel-compatible serverless API routes in `api/auth`
